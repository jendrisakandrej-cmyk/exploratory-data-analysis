# Exploratory Data Analysis & Visualisation

Data cleaning, exploration and visualisation across two real-world datasets
using Python in Jupyter Notebook.

## Built With
- Python
- pandas
- matplotlib
- Jupyter Notebook

## Datasets
- **Netflix content dataset** — cleaned and explored titles, genres, 
release years and content distribution
- **Student wellbeing dataset** — analysed patterns related to student 
health, habits and academic performance

## What I Did
- Cleaned messy and inconsistent data using pandas
- Performed exploratory data analysis (EDA)
- Created visualisations to identify trends and patterns
- Drew conclusions from the data using matplotlib charts

## What I Learned
- Data cleaning techniques with pandas
- Exploratory data analysis workflow
- Data visualisation with matplotlib
- Working in Jupyter Notebook environment
